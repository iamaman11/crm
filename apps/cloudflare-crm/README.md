# CRM — простой тестовый пилот на Cloudflare

Один Worker обслуживает React 19 + Vite и API. Данные — в одной D1.

Клиенты, контакты, сделки и задачи: создание, просмотр, редактирование, поиск и удаление. Все данные тестовые. Вход — существующий Cloudflare Access, при первом человеческом входе создаётся пустое рабочее пространство.

- API: `worker/index.mjs`
- UI: `web/src/main.jsx`, `web/src/styles.css`
- D1: `migrations/0001_initial.sql`
- Cloudflare: `wrangler.jsonc`
- Тесты: `npm test`, UI-сборка: `npm run build`

GitHub Actions доверенной ветки публикует Worker + Static Assets и применяет D1-миграцию. https://crm-dev.crm-5bd5e1e1.workers.dev

Усиленная защита и дополнительные инфраструктурные механизмы — после реального production.

После публикации GitHub Actions запускает реальный Chromium на опубликованном URL: клиент → контакт → сделка → задача → обновление страницы → поиск → правки → мобильный экран → удаление. Технический вход используется только для пилотного E2E.

Технические входы `crm-e2e-a` и `crm-e2e-b` имеют разные рабочие пространства. Браузерная приёмка проверяет, что пользователь видит и изменяет свои записи, но не записи другого пользователя.

В разделе «Сделки» есть переключатель «Таблица / Воронка». Воронка показывает пять этапов, число и сумму сделок по каждому этапу. Этап можно поменять прямо на карточке без открытия формы; изменение сохраняется в D1 и переживает обновление страницы. На телефоне колонки идут вертикально.
