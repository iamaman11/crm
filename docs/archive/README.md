# Архив документов CRM

**Архивные Markdown-файлы предназначены для сохранения исходных требований, реализаций и исторических решений. Они не являются действующим продуктовым или архитектурным планом.**

Работа и текущие статусы: [#484 — единый продуктовый план](https://github.com/iamaman11/crm/issues/484), [#487 — исполнительный курсор](https://github.com/iamaman11/crm/issues/487). Технический контракт — [apps/cloudflare-crm/ARCHITECTURE.md](../../apps/cloudflare-crm/ARCHITECTURE.md).

- `cloudflare-snapshots/` — замороженные полные каталоги SK-00: 554 продуктовых требования и исторические проверки 93 Rust crates. Они нужны как доказательная база, но статусы не синхронизируются в нескольких местах.
- `legacy-main/` — полные прежние нормативные PostgreSQL/main roadmap, status, архитектура, governance, пакеты и исторический docs/README.

Исходные пути заменены короткими указателями: старые ссылки продолжают вести в архив, а новые решения записываются в Issues.
